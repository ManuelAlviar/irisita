# Para Iris 🤍

Versión elegante y responsive para GitHub Pages.

## Archivos

- `index.html`
- `styles.css`
- `script.js`

## Tecnologías

- HTML5
- CSS3
- JavaScript
- YouTube IFrame Player API

## Responsive

La interfaz está adaptada para:

- celulares verticales
- celulares horizontales
- tablets
- laptops
- monitores grandes

La carta se abre como un panel responsive y tiene scroll interno cuando el contenido supera la altura disponible.

## Cambiar la canción

En `script.js` busca:

```js
const YOUTUBE_VIDEO_ID = "rYwXfmgNSVI";
```

Solo reemplaza el ID.

Ejemplo:

```text
https://www.youtube.com/watch?v=rYwXfmgNSVI
```

El ID es:

```text
rYwXfmgNSVI
```

## GitHub Pages

1. Crea un repositorio.
2. Sube `index.html`, `styles.css` y `script.js`.
3. Ve a `Settings`.
4. Abre `Pages`.
5. Selecciona `Deploy from a branch`.
6. Elige `main`.
7. Elige `/ (root)`.
8. Guarda.

## Música

La página intenta iniciar la canción al tocar la rosa.

Los navegadores pueden bloquear reproducción automática con sonido.
Por eso también queda visible el botón `Nuestra canción` arriba a la derecha.
